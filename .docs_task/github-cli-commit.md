# GitHub CLI Commit Guide (Windows)

You're helping me commit changes using GitHub CLI on **Windows**.  
Please follow the exact rules below:

---

## ✅ What You Should Do

- Use **GitHub CLI** (`gh`) commands only.
- Commit with a **clear, concise, and meaningful message**.
- Use **present tense** for commit messages (e.g., "Add", "Fix", "Improve").
- Push directly to the **current branch** (do **not** create a new branch).

### 💬 Example Commit Messages
- `Fix button alignment on mobile`
- `Add form validation to signup page`
- `Refactor navbar for clarity`

---

## ❌ What You Should NOT Do

- ❌ Do not create a new branch.
- ❌ Do not write vague messages like "Update" or "Fixes".

---

## 🔧 Additional Notes

- I'm on **Windows**, so make sure commands are compatible.
- If needed, use `gh auth login` to ensure I'm authenticated.
